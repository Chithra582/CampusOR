# Smart Notification Dispatcher Skill

## Overview
Ensures timely user arrival by broadcasting real-time updates and proximity warnings across preferred digital channels.

## Operations
1. Fires proximity notifications when user moves within top 3 positions in line.
2. Sends immediate counter call notifications ("Counter 4 Calling: Token A-102").
3. Manages grace-period countdown pings for absent users.
4. Pushes anonymized token call events to public display boards and mobile PWAs.
